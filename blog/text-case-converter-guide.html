💡 รูปแบบการแปลงเคสตัวอักษรยอดนิยมมีอะไรบ้าง?

เครื่องมือ Text Case Converter รองรับการแปลงรูปแบบข้อความหลักๆ ที่ใช้บ่อยดังนี้:

1. UPPERCASE (ตัวพิมพ์ใหญ่ทั้งหมด)

เปลี่ยนตัวอักษรภาษาอังกฤษทุกตัวให้เป็นตัวพิมพ์ใหญ่ เหมาะสำหรับสร้างหัวข้อ รหัสอ้างอิง หรือเน้นข้อความสำคัญ เช่น:

hello world ➔ HELLO WORLD

2. lowercase (ตัวพิมพ์เล็กทั้งหมด)

เปลี่ยนตัวอักษรทั้งหมดให้เป็นตัวพิมพ์เล็ก เหมาะสำหรับการจัดระเบียบข้อมูล อีเมล หรือคีย์เวิร์ด SEO เช่น:

HELLO WORLD ➔ hello world

3. Title Case (ขึ้นต้นตัวใหญ่ทุกคำ)

เปลี่ยนอักษรตัวแรกของทุกคำให้เป็นตัวพิมพ์ใหญ่ เหมาะสำหรับการตั้งชื่อบทความ ชื่อหนังสือ หรือชื่อเรื่อง เช่น:

hello world from toolhub ➔ Hello World From Toolhub

4. Capitalized Sentence (ขึ้นต้นตัวใหญ่ต้นประโยค)

ปรับรูปแบบให้ตรงตามหลักไวยากรณ์ โดยอักษรตัวแรกสุดของประโยคหรือหลังจุดจบประโยคจะเป็นตัวพิมพ์ใหญ่ เช่น:

hello world. this is a test. ➔ Hello world. This is a test.

5. camelCase (สำหรับโปรแกรมเมอร์)

รูปแบบที่คำแรกจะพิมพ์เล็ก และคำถัดไปจะขึ้นด้วยตัวพิมพ์ใหญ่โดยไม่มีการเว้นวรรค นิยมใช้ในการตั้งชื่อตัวแปรในภาษาเขียนโค้ด เช่น JavaScript, Java, C#:

user profile name ➔ userProfileName

6. kebab-case (สำหรับ URL และ CSS)

เชื่อมทุกคำด้วยเครื่องหมายขีดกลาง (-) และใช้ตัวพิมพ์เล็กทั้งหมด นิยมใช้กับการตั้งชื่อไฟล์ สลัก URL (SEO Slug) และคลาสใน CSS:

text case converter ➔ text-case-converter

7. snake_case (สำหรับฐานข้อมูลและ Python)

เชื่อมทุกคำด้วยเครื่องหมายขีดล่าง (_) และใช้ตัวพิมพ์เล็กทั้งหมด นิยมใช้ในการตั้งชื่อฟิลด์ในฐานข้อมูล (SQL) หรือตัวแปรภาษา Python:

created at date ➔ created_at_date
