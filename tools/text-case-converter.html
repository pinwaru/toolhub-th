UPPERCASE

เปลี่ยนตัวอักษรทั้งหมดเป็นตัวพิมพ์ใหญ่ ใช้สำหรับเน้นหัวข้อหรือรหัสอ้างอิง

lowercase

เปลี่ยนตัวอักษรทั้งหมดเป็นตัวพิมพ์เล็ก เหมาะสำหรับทำความสะอาดอีเมลหรือคีย์เวิร์ด

Title Case

เปลี่ยนอักษรตัวแรกของทุกคำให้เป็นตัวพิมพ์ใหญ่ เหมาะสำหรับตั้งชื่อบทความหรือชื่อหนังสือ

camelCase

คำแรกพิมพ์เล็ก คำถัดไปขึ้นด้วยตัวใหญ่ นิยมใช้ตั้งชื่อตัวแปรในการเขียนโปรแกรม

kebab-case

เชื่อมทุกคำด้วยขีดกลาง (-) นิยมใช้ตั้งชื่อไฟล์ สลัก URL และคลาสใน CSS

snake_case

เชื่อมทุกคำด้วยขีดล่าง (_) นิยมใช้ในฐานข้อมูลและภาษา Python
